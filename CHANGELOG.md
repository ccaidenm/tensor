# Changelog

All notable changes to Tensor are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-24

### Added

- Engine-driven pagination: real pages, incremental layout, warm-output parity
- Pageless mode: continuous writing without sheets, with a slim ruler
- Sections with their own geometry, breaks, and per-section settings
- Headers and footers with different-first-page and page-number fields
- Multiple columns: presets, manual column breaks, and balanced column endings
- Command palette for every command, typed table sizes, and Unicode entry
- Spell and grammar checking via LanguageTool, online or a local runtime
- Translation via LibreTranslate, Google, DeepL, or on-device models
- DOCX import and export through a two-way mapping layer with loud reports
- Markdown import and export with an explicit lossy-confirmation contract
- Printing and PDF export with a preview, duplex picker, and page ranges
- Watermarks: text or image, whole document or per section, with live preview
- Per-page and per-section page backgrounds
- Tables with a grid picker, header pinning, merged cells, and a table panel
- Reference tables: ToC, Table of Figures, and Index from headings and captions
- Display equations written in LaTeX, typeset by KaTeX
- Images: block and inline, text wrap, resizing, captions, and alt text
- Custom styles layered over built-ins, with per-document registries
- Font management: bundled families, system fonts, uploads, and a browser
- Unicode and symbol picker with recently used groups
- Line numbers with continuous and per-page modes
- Horizontal and vertical rulers with tab stops, margin, and indent dragging
- Comments: anchored threads in the gutter, replies, and resolution
- Focus mode for distraction-free writing
- Document statistics: words, characters, sentences, and reading time
- Accessibility Check: alt text, headings, and color contrast findings
- First-run setup wizard with privacy-first defaults throughout
- Recent documents, templates, and recovery of unsaved drafts
- Autosave with crash-safe recovery snapshots
- Custom topbar: accent themes, window control side, and live title
- Update auto-check that notifies when a newer GitHub release is available
- Internationalization runtime with English as the source of truth
- Non-printing characters, break marks, and boundary-content view toggles
- Context menu with image, table, and text surfaces
